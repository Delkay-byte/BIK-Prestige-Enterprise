## Before Opening

### System Check
- [ ] Application is running and accessible
- [ ] Database connection verified (check for DEVELOPMENT badge if local)
- [ ] Backup completed — `backups/dev-pre-pilot-YYYYMMDD_HHMMSS.db`
- [ ] Admin login tested — can reach dashboard
- [ ] All pilot worker accounts tested — can log in and reach dashboard
- [ ] All pilot collector accounts tested — can log in and reach dashboard

### Location Setup
- [ ] Pilot MoMo location(s) created in system
- [ ] Location details match physical location (name, address, code)
- [ ] Worker assigned to correct location
- [ ] Worker knows their login credentials

### Susu Setup
- [ ] Pilot customers registered in system
- [ ] Customer details match physical records (name, phone, daily contribution)
- [ ] Customer cards/accounts created
- [ ] Card fee (GH₵10) recorded
- [ ] Collectors assigned to customers
- [ ] Collectors know their login credentials

### Physical Records
- [ ] Physical Susu cards available for each customer
- [ ] Daily marking sheets ready
- [ ] Cash handling procedures confirmed

---

## During the Day

### MoMo Operations
- [ ] Worker logs in successfully
- [ ] Worker opens daily account
- [ ] Opening balance entered (MoMo float + cash)
- [ ] Daily operations recorded throughout the day
- [ ] Expenses recorded where applicable
- [ ] Closing balance entered at end of day
- [ ] Worker submits account
- [ ] Admin can see submission on dashboard

### Susu Operations
- [ ] Customer payment recorded (collector or direct office)
- [ ] Payment amount matches daily contribution
- [ ] Multi-day payment tested if applicable
- [ ] Physical card marking agrees with digital record
- [ ] Collector records collection on mobile
- [ ] Collection confirmation received

### Monitoring
- [ ] Admin checks dashboard periodically
- [ ] Any discrepancies noted immediately
- [ ] Any user confusion recorded in PILOT-FEEDBACK.md

---

## End of Day

### MoMo Close
- [ ] All expected MoMo reports submitted
- [ ] Pending locations reviewed (any not submitted?)
- [ ] Discrepancies reviewed (any non-zero variance?)
- [ ] Discrepancy evidence preserved if any

### Susu Close
- [ ] Outstanding customers identified (who didn't pay?)
- [ ] Collector collections checked
- [ ] Remittances reviewed
- [ ] Withdrawals reviewed (if any)
- [ ] Commission amounts verified
- [ ] Digital records compared against physical cards

### Backup & Documentation
- [ ] End-of-day backup created
- [ ] Any issues recorded in PILOT-FEEDBACK.md
- [ ] Physical records stored safely
- [ ] Any discrepancies documented with evidence
